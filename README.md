# MTA Daily Ridership: Post-COVID Recovery Analysis & Next-Month Forecast

DEPI Graduation Project – Data Analysis Track

## Team

- Mohamed Hossam

## Description
This project analyzes how MTA ridership recovered after COVID-19 using the MTA Daily Ridership dataset (March 2020 – October 2024). It also forecasts next month's ridership and presents the results in a Power BI dashboard.

## Repository Structure
- 01-Planning: proposal, Gantt chart / tasks / risks, KPIs
- 02-Requirements: requirements document and review summary
- 03-Design: dashboard design
- 04-Implementation: data cleaning, model, Power BI dashboard
- 05-Docs-Testing: documentation and test cases
